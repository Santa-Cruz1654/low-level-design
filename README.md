# Low-Level Design in Python

A collection of Low-Level Design (LLD) problems implemented in Python.

This repository is part of my journey to understand object-oriented design, SOLID principles, design patterns, and scalable software architecture.

## LLD Problems

| # | Problem | Concepts |
|---|---|---|
| 01 | [Document Editor](./01-document-editor) | OOP, SOLID, Abstraction, Polymorphism, Dependency Injection |
| 02 | [Music Player](./02-music-player) | OOP, SOLID, Strategy, Adapter, Factory, Singleton, Facade, Composition |

Each problem includes the implementation, a design explanation, and lessons learned.

## Learning Goals

- Object-Oriented Programming
- SOLID Principles
- Abstraction and Encapsulation
- Inheritance and Polymorphism
- Composition and Aggregation
- Dependency Injection
- Design Patterns (Creational, Structural, Behavioral)
- Clean Code
- Testable and extensible designs
- LLD interview preparation
